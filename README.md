# SIM - Security Incident Mapping

## Overview
SIM (Security Incident Mapping) is a web-based platform designed to reduce campus crime by enabling students, staff, and landlords to quickly report and track security incidents. The system provides a structured way to log crimes such as theft, assault, vandalism, and harassment, while ensuring anonymity and fast response.

## Features
- Quick incident reporting via web form
- Anonymous submissions supported
- Role-based access (students, staff, landlords, admins)
- Incident tracking and statistics dashboard
- Exportable reports for security management
